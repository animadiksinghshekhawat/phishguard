How It Works

Five layers of detection run concurrently in real-time.

01

URL Structure (8 features)

Analyses length, IP usage, shorteners, hyphens, @ symbols, subdomain depth, HTTPS, and non-standard ports — instantly, with no network calls.

02

DNS & WHOIS (4 features)

Checks domain age, registration length, DNS existence, and SURBL blacklist status using live lookups run in parallel.

03

Page Content (10 features)

Fetches the live page and analyses forms, iframes, favicon origin, external resources, JS behaviour, and redirect chains.

04

Reputation (4 features)

Estimates PageRank, global traffic, backlinks, and Google indexing using the Open PageRank API and domain-trust heuristics.

05

ML Classification

All 30 features feed into a Random Forest (97.4% accuracy) trained on 11,054 labelled URLs. The highest of ML score and guardrail score is used.

06

Blended Score

Deterministic safety guardrails prevent high-confidence phishing patterns from being masked by neutral feature values.
